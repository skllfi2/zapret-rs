# Живой smoke: то, что требует прав администратора

Офлайн-гейты (ruff, mypy, 172 теста, test_verify.py) зелёные — этот чек-лист покрывает то,
что нельзя проверить без реальной Windows-среды: SCM, живой winws, PowerShell-тест и GUI.

Запуск: `smoke_live.bat` (или `python smoke_live.py`) — скрипт сам запросит UAC.
Отчёт печатает `[PASS]/[FAIL]` по каждому пункту и ненулевой код выхода при провале.

## 1. Живое применение стратегии end-to-end — `smoke_live.bat`

Что проверяется автоматически:

- [ ] разбор выбранного `*.bat` даёт аргументы winws.exe;
- [ ] `apply_strategy()` пересоздал binPath службы и перезапустил её;
- [ ] служба `zapret` в состоянии **Running**;
- [ ] процесс **winws.exe** реально запущен (не только «служба стартовала»);
- [ ] binPath службы указывает на `winws.exe` со всеми аргументами;
- [ ] файл `.strategy` записан (статус в UI покажет эту стратегию).

Дублируется вручную через UI: выбрать стратегию → «Применить» → статус окна/трея
показывает стратегию и `winws.exe running=True`. Проверить, что интернет/Discord/YouTube
фактически работают (это цель DPI-обхода).

## 2. Реальный `utils\test zapret.ps1` — `smoke_live.bat --tests`

Схема оригинала: **Remove Services → Run Tests** (тесты требуют службы без установленной).

- [ ] служба удаляется перед тестами (в UI это пункт «2. Удалить службы»);
- [ ] пре-чеки пусты: права админа, `curl`, наличие `test zapret.ps1`;
- [ ] скрипт отвечает на свои `Read-Host` (тип теста/режим уходят в stdin), вывод идёт
      в UI потоком с цветными маркерами `[+]`/`[?]`/`[X]`;
- [ ] появился файл `utils\test results\test_results_*.txt` со строкой `Best strategy:`;
- [ ] после тестов применяется Best strategy (иначе прежняя) — машина остаётся рабочей.

Длинный прогон (все конфиги) — до 30 мин (`--timeout 1800`). Быстрый вариант:
`smoke_live.bat --tests --mode 2 --selection 3 --yes` (один конфиг).
В UI: «Тесты» → тип/режим → «Запустить»; кнопка «Применить лучшую стратегию» после тестов.

## 3. Визуальный smoke (только глазами) — UI: `start-gui.bat` или `dist\zapret-simple.exe`

**Трей**

- [ ] иконка появляется, тултип показывает текущий статус службы/winws;
- [ ] цвет иконки меняется вместе со статусом (запущена/остановлена);
- [ ] ПКМ: «Показать» разворачивает окно, «Выход» закрывает приложение;
- [ ] двойной клик по иконке разворачивает окно.

**RU / EN**

- [ ] кнопка `RU`/`EN` в шапке: переключает меню, диалоги, вывод и тексты ядра на месте;
- [ ] выбор переживает перезапуск (`%LOCALAPPDATA%\zapret-simple\ui_settings.json`);
- [ ] подписи меню трея тоже перестраиваются.

**UAC**

- [ ] запуск без прав → один UAC-запрос на старте → окно открывается с правами;
- [ ] отказ от UAC → приложение работает без прав, админ-действия вежливо отвечают
      «Требуются права администратора» (без падений);
- [ ] пункт меню «Повысить права» (relaunch_admin) перезапускает окно через UAC;
- [ ] в экзекутабле (`dist\zapret-simple.exe`) та же логика: `frozen=True`, лог пишется
      в `%LOCALAPPDATA%\zapret-simple\zapret.log` (не рядом с exe).

## После прогона

- Если всё PASS — живая часть закрыта; в этом чек-листе отметьте пункты и, при желании,
  закоммитьте `smoke_live.py`/`smoke_live.bat`/`SMOKE.md`.
- Провалы любого пункта — приложите вывод `smoke_live.py` и последние строки `zapret.log`.
